# Мой фокус | Трекер задач

Простой и удобный трекер задач в темной теме, который работает прямо в браузере. Позволяет добавлять задачи, отмечать их выполненными, фильтровать и удалять.

## Демо

Посмотреть проект вживую можно здесь: [ссылка на GitHub Pages]

## Функционал

- ➕ **Добавление задач** с автоматической фиксацией даты создания.
- ✅ **Отметка выполнения** (клик по тексту задачи).
- 🗑️ **Удаление задач** (клик по крестику).
- 🔍 **Фильтрация** (Все / Активные / Выполненные).
- 📊 **Счетчик** (показывает, сколько выполнено из общего числа).
- 💾 **Сохранение данных** (задачи не пропадают при перезагрузке страницы благодаря `localStorage`).
- 📱 **Адаптивная верстка** (удобно пользоваться как на компьютере, так и на телефоне).

## Технологии

- HTML5 (семантическая верстка)
- CSS3 (Flexbox, кастомные свойства, медиазапросы)
- JavaScript (ES6, работа с DOM, события, `localStorage`)
- Шрифты и иконки: встроенные эмодзи.
